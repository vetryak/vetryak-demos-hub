# GEMINI.md

As instruções do repositório ficam em [`AGENTS.md`](./AGENTS.md) (fonte única para todos os
agentes). Leia e siga esse arquivo.

Dica: no Gemini CLI você pode apontar o arquivo de contexto direto para o `AGENTS.md`
em `.gemini/settings.json`:

```json
{ "context": { "fileName": ["AGENTS.md", "GEMINI.md"] } }
```
